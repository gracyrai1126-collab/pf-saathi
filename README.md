# PF Saathi 🔐

**Understanding Your Provident Fund | IMPACTX 2026**

PF Saathi is a Python-based prototype that helps employees understand provident fund contribution records, identify possible discrepancies, track claim statuses, prepare neutral queries, and recognise potential scams.

## Features
- Contribution ledger analysis
- Possible discrepancy classification
- Claims status tracker
- Neutral query generator
- Scam awareness and OTP safety guidance
- PF information and official service links

## Technology
- Python
- Streamlit
- Pandas

## Run locally

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## Data and safety

This is a hackathon prototype. Demo records are fictional and do not represent actual EPFO account data. The application does not log in to EPFO accounts or verify live claims. Results are informational and should be checked against official records.

Never enter passwords, OTPs, or sensitive personal identifiers.
